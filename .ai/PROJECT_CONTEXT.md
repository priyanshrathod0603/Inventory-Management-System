# Project Context

## Project
**Project Name:** Stock Management System (SMS)

**Project Type:** Production-grade inventory / stock management and retail POS system.

**Primary Goal:** Build a reliable, scalable system for managing products, inventory, purchases, sales, customers, suppliers, billing, payments, reports, users, permissions and related business operations.

The system should be suitable for serious business usage and designed with scalability, security, maintainability and auditability in mind.

## Core Philosophy
The system provides:
* Real-time inventory updates
* Reliable transactional operations
* Fast counter billing
* Accurate stock tracking
* Complete transaction history
* Strong role-based access control (RBAC) with granular permissions
* Comprehensive auditability
* Professional invoices (58mm/80mm thermal receipts and A4 GST tax invoices)
* Reporting and analytics
* Extensible architecture
* AI-friendly development workflow

## Current Development Stage
**Project Brain Finalized & Frozen — Pre-Implementation Gate**

The requirements, system architecture, database design, API contracts, UI/UX design system, security rules, coding rules, and testing strategies are completely specified and frozen.

The application code itself has NOT been implemented yet.

## Scope Summary
* **Phase 1 Scope (Desktop-Only):** Production-grade web-based desktop application for counter billing (POS), inventory management, procurement, customer/supplier ledgers, sales returns, purchase returns, batch/expiry tracking, multi-warehouse stock management, reports, notifications, audit logs, and administration.
* **Phase 2 Future Scope (Post-Phase 1):** Mobile/PWA applications, device camera scanning, AI demand forecasting, OCR invoice intake, multi-branch cloud sync, external accounting integrations, and direct GST portal e-Invoicing/e-Way bill filing.
